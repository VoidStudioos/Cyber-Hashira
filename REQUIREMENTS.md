# System Requirements

## 1. Supported Operating Systems

- **Windows 10 / 11 (64-bit):**
  - Architecture: x86_64
  - WebView2 Runtime (pre-installed on Windows 10/11)
  - Optional: Python 3.10+ (for Python-based security modules)
- **Ubuntu 22.04 LTS / 24.04 LTS (64-bit):**
  - Architecture: x86_64
  - Required packages: `libwebkit2gtk-4.1-dev`, `libssl-dev`, `libgtk-3-0`
  - Python 3.10+
- **macOS (Preview):**
  - macOS 12 Monterey or newer (Intel & Apple Silicon)

---

## 2. Hardware Recommendations

- **Minimum:**
  - CPU: 2 Cores
  - RAM: 4 GB
  - Disk: 500 MB (Lightweight Host only)
- **Recommended (For multi-module scanning):**
  - CPU: 4+ Cores
  - RAM: 8+ GB
  - Disk: 10 GB SSD (to store heavy scan captures and evidence)
